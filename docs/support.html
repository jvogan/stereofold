Support

Updated September 30, 2026

Jacob Vogan publishes Stereofold as an MIT-licensed open-source project. Use the Stereofold issue tracker to report a reproducible problem or request a feature.

Report a problem

Include the information needed to reproduce the problem:

  • Stereofold version or commit and installation route.
  • Operating system, agent host, and Node.js version.
  • Headset model and browser version, when relevant.
  • Steps taken, expected result, and observed result.
  • A public PDB example or a small example you may share.

Remove private details from error messages and screenshots. Keep credentials, pairing codes, complete viewer links, local usernames, confidential structures, voice recordings, and unrelated windows out of public issues.

Installation and troubleshooting

The local runtime needs Node.js 22 or newer. macOS is the tested desktop platform. Voice and device launch features have additional optional prerequisites; typed inspection works without them.

Use the installation guide and bundled setup skill. For headset sharing, check connection state and rendered receipts before assuming a change reached the headset. Other browsers can use manual private HTTPS pairing when a launch shortcut is unavailable.

The project documentation describes supported routes and tested host/device scope. A simulator or browser test establishes the behavior exercised in that environment.

Security

Read the security reporting instructions before reporting a vulnerability. Keep vulnerability details out of public issues.

Response expectations

The issue tracker provides community support without a guaranteed response time. Agent hosts and optional third-party services have their own support channels.
